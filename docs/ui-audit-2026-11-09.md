# UI/UX audit, 9 Nov 2026 (dev build on Oppo CPH2487, dark mode, stage site)

Screens walked on the phone: Home, Inbox, Transaction detail, Expense account picker, Check-before-creating (Confirm), Activity, Settings.
Not walked live (nothing created on purpose): Result screen, Party/Amount/Invoices steps, Login and setup wizard, light mode, TalkBack, large font.

## A. Bugs (something is wrong)
1. **Tab icons missing.** `app/(tabs)/_layout.tsx` hides them (`tabBarIconStyle: { display: 'none' }`); no icon library is installed. The design mockup has an icon per tab. Fix: add `react-native-svg` (one native rebuild) and use the mockup's icon paths.
2. **"Unrecognised account ending …" notices never clear.** The `unrecognised_account:<last4>` flag is only removed by the Dismiss button, even after the account is mapped in Settings. Fix: drop any flag whose last-4 is covered by a mapping, when the Inbox loads.
3. **Those notices swallow the screen.** Three notices are ~290 px each and push the transactions below the fold. Fix: one compact notice ("3 accounts not set up: 3455, 6507, 8129", Open Settings).
4. **Wrong chip on card spends.** Merchant rows (Facebook, Anthropic) show "Who is this?"; it should be "What was this?" (there is no person).
5. **Continue button looks enabled with nothing selected** on the expense account picker (verify whether it really is disabled).
6. **Filter field on the account picker renders as an empty box** with the label above it (no placeholder text/search icon).

## B. Confusing or inconsistent
7. Dates: Activity shows `2026-11-06`; elsewhere `8 Nov 2026`.
8. Minus signs: Activity `-₹2,194.00` (hyphen), Inbox `−₹1,231.92` (true minus).
9. Detail card shows the internal "AutoLedger reference AL-5876…" as a main row, and "2 messages about this payment" with no explanation.
10. "Personal" is explained twice (greyed row text plus a blue banner at the bottom, below the fold). One place is enough, and it should link to Settings.
11. Confirm screen jargon: a technical sentence "Journal Entry (draft): expense … UTR/ref AL-…" repeats the rows below it; "Debit/Credit" labels for a non-accountant. Better: "Booked as expense: …", "Paid from: …".
12. Foreign card spend shows `−USD 100.00` with no rupee value (known limitation R52a): the user can't judge it and must type the rupee amount later.
13. Activity: "Payment Entry ACC-PAY-2026-00044" is ERP jargon; "Draft" chip looks like a button; Undo is a large red outlined button that dominates the card; section header is ALL CAPS while Inbox uses sentence case.
14. Settings: "Messages that could not be read: 0" is noise at zero; no Sign out visible without scrolling; no way to edit one account (only "Run setup again"); no app version; debug link visible in dev builds only (fine).
15. Home: bank label repeats the name ("IDFC First - Zen Pivot - IDFC First"); no trust line under the balance (the mockup has "Matches the balance in the latest bank message"); credit card outstanding is not shown; large empty area below the cards.

## C. Visual polish
16. Tab bar is too tall: about 100 px of empty space under the labels (height 64 plus a second bottom inset).
17. Look and feel is generic: no brand typeface (the mockup uses Public Sans / IBM Plex Mono), no amount colours (money in/out), flat cards of equal weight, big banner on Home dominates the balance.
18. Long merchant names wrap to two lines in the Inbox row ("ANTHROPIC* CLAUDE SUB"); no truncation rule.
19. Row cards in Inbox have a large left icon circle with the same arrow for every type; card vs bank vs UPI is only in small grey text.

## D. Not verified
Light mode, TalkBack, 200% font size, landscape, keyboard overlap on text fields, Result/Party/Amount/Invoices screens, Login and setup wizard on this build.
